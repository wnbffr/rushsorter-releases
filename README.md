# Athlete Rush Sorter

Sort bodybuilding-competition rushes by athlete number, locally on your computer.

## Download

Go to the **[Releases](../../releases/latest)** page and pick your installer:

| System | File |
|---|---|
| Windows 10/11 (x64) | `Athlete.Rush.Sorter-<version>-win-x64.exe` |
| macOS Apple Silicon (M1 or newer) | `Athlete.Rush.Sorter-<version>-mac-arm64.dmg` |
| macOS Intel (iMac / MacBook up to 2020, macOS 12+) | `Athlete.Rush.Sorter-<version>-mac-x64.dmg` |

The installers are **not code-signed** yet:
- **Windows**: SmartScreen shows "Windows protected your PC": click *More info* then *Run anyway*.
- **macOS**: right-click the app, choose *Open*, then confirm.

Everything runs on your machine; nothing is uploaded. GPU acceleration: DirectML on Windows (NVIDIA, AMD, Intel), CoreML on Apple Silicon.
